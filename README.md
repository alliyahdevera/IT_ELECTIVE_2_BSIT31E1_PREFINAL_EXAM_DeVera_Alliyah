## PreFinalExamMVC

### Overview
A simple ASP.NET Core MVC website for the IT Elective 2 PreFinal Examination.

This website displays different topics containing questions from PreFinal Examination docx with answers.

## Topics

- Relational Data Modeling
- Conceptual Data Architecture
- Data Normalization and Structural Integrity
- Structured Query Language

## Features

- Topic selection page
- Question and answer cards
- Simple user interface

## Technologies Used

- ASP.NET Core MVC
- Razor Views
- C#
- HTML
- CSS

# How to Run the Application

## Prerequisites
- Visual Studio 2026
- .NET 10 SDK

## Steps

1. Clone the repository.

   ```bash
   git clone https://github.com/your-username/your-repository.git
   ```

2. Open the solution (`.sln`) file in **Visual Studio**.

3. Press **Ctrl + F5** or click **Start** to build and run the application.

4. Your browser will open automatically to (The port number may vary):

   ```
   https://localhost:xxxx
   ```
